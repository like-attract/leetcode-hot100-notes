链表递归的核心不是“背代码”，而是要理解一句话：

> **把链表看成：当前节点 head + 后面的子链表 head.next。**  
> 递归函数负责处理整个链表，那么 `head.next` 这部分可以交给递归去处理，当前层只负责把 `head` 和递归结果接起来。

---

# 1. 递归链表题的三个问题

做链表递归题时，先问自己：

## ① 这个递归函数到底要干什么？

比如：

```python
reverseList(head)
```

它的含义不是“怎么反转”，而是：

> 输入一个链表头节点 `head`，返回反转后的链表头节点。

再比如：

```python
mergeTwoLists(l1, l2)
```

含义是：

> 输入两个有序链表，返回合并后的有序链表头节点。

一定要先明确函数语义。

---

## ② 递归什么时候结束？

也就是 base case。

链表递归最常见的终止条件：

```python
if head is None:
    return None
```

或者：

```python
if head is None or head.next is None:
    return head
```

比如反转链表时，如果链表为空，或者只剩一个节点，就不需要反转。

---

## ③ 当前这一层要做什么？

这是最关键的一步。

递归的核心思想是：

> **假设后面的链表已经被递归处理好了，我只处理当前节点 head。**

比如反转链表：

```python
new_head = reverseList(head.next)
```

你可以理解为：

> 我已经相信 `head.next` 后面的部分已经被反转好了，现在我只需要把 `head` 接到反转后的链表末尾。

---

# 2. 例子一：反转链表

题目：反转链表。

```text
1 -> 2 -> 3 -> 4 -> None
```

反转后：

```text
4 -> 3 -> 2 -> 1 -> None
```

递归写法：

```python
def reverseList(head):
    if head is None or head.next is None:
        return head

    new_head = reverseList(head.next)

    head.next.next = head
    head.next = None

    return new_head
```

---

## 怎么理解？

假设链表是：

```text
1 -> 2 -> 3 -> None
```

调用：

```python
reverseList(1)
```

它先递归处理：

```python
reverseList(2)
```

继续递归：

```python
reverseList(3)
```

到 `3` 的时候：

```python
3.next is None
```

所以返回 `3`。

也就是说，递归返回后，`2 -> 3` 已经变成了：

```text
3 -> 2 -> None
```

然后处理 `1`：

```python
head.next.next = head
head.next = None
```

也就是：

```python
2.next = 1
1.next = None
```

最终变成：

```text
3 -> 2 -> 1 -> None
```

---

## 关键理解

```python
new_head = reverseList(head.next)
```

这句话的意思是：

> 后面的链表已经反转好了，`new_head` 是反转后链表的头。

当前层只负责：

```python
head.next.next = head
head.next = None
```

也就是把当前节点 `head` 接到后面反转链表的末尾。

# 3. 例子二：合并两个有序链表

题目：合并两个有序链表。

```text
l1: 1 -> 3 -> 5
l2: 2 -> 4 -> 6
```

合并后：

```text
1 -> 2 -> 3 -> 4 -> 5 -> 6
```

递归写法：

```python
def mergeTwoLists(l1, l2):
    if l1 is None:
        return l2

    if l2 is None:
        return l1

    if l1.val <= l2.val:
        l1.next = mergeTwoLists(l1.next, l2)
        return l1
    else:
        l2.next = mergeTwoLists(l1, l2.next)
        return l2
```

---

## 怎么理解？

比较两个链表的头节点：

```python
l1.val <= l2.val
```

如果 `l1` 更小，那么合并后的链表头一定是 `l1`。

但是 `l1.next` 是谁呢？

它应该是：

```python
mergeTwoLists(l1.next, l2)
```

也就是：

> 把 `l1` 后面的部分和 `l2` 继续合并。

所以：

```python
l1.next = mergeTwoLists(l1.next, l2)
return l1
```

同理，如果 `l2` 更小：

```python
l2.next = mergeTwoLists(l1, l2.next)
return l2
```

---

## 递归函数语义

```python
mergeTwoLists(l1, l2)
```

表示：

> 返回 `l1` 和 `l2` 合并后的有序链表头节点。

当前层只判断：

```text
当前 l1 和 l2 哪个更小？
```

然后把小的那个节点作为当前结果，剩下的交给递归。

# 4. 例子三：两两交换链表中的节点

题目：两两交换链表中的节点。

```text
1 -> 2 -> 3 -> 4 -> None
```

交换后：

```text
2 -> 1 -> 4 -> 3 -> None
```

递归写法：

```python
def swapPairs(head):
    if head is None or head.next is None:
        return head

    first = head
    second = head.next

    first.next = swapPairs(second.next)
    second.next = first

    return second
```

---

## 怎么理解？

当前层只处理前两个节点：

```python
first = head
second = head.next
```

也就是：

```text
first -> second -> 后面的链表
```

后面的链表交给递归：

```python
first.next = swapPairs(second.next)
```

然后把 `first` 和 `second` 交换：

```python
second.next = first
```

最后返回新的头节点：

```python
return second
```

# 5. 例子四：删除链表倒数第 N 个节点

题目：删除链表倒数第 `n` 个节点。

```text
1 -> 2 -> 3 -> 4 -> 5
n = 2
```

删除倒数第二个节点 `4`：

```text
1 -> 2 -> 3 -> 5
```

递归写法：

```python
def removeNthFromEnd(head, n):
    dummy = ListNode(0)
    dummy.next = head

    def dfs(node):
        if node is None:
            return 0

        count = dfs(node.next) + 1

        if count == n + 1:
            node.next = node.next.next

        return count

    dfs(dummy)
    return dummy.next
```

---

## 怎么理解？

这个递归是典型的 **后序递归**。

因为我们要知道：

> 当前节点后面还有多少个节点？

所以要先递归到链表末尾，再一层一层往回计算。

```python
count = dfs(node.next) + 1
```

表示：

> 当前节点后面有 `dfs(node.next)` 个节点，所以当前节点是倒数第 `count` 个节点。

如果：

```python
count == n + 1
```

说明当前节点是待删除节点的前一个节点。

于是：

```python
node.next = node.next.next
```

删除目标节点。

# 6. 递归的两种常见模式

## 模式一：先递归，再处理当前节点

典型题目：

- 反转链表
- 删除倒数第 N 个节点
- 判断回文链表

例如：

```python
def reverseList(head):
    if head is None or head.next is None:
        return head

    new_head = reverseList(head.next)

    head.next.next = head
    head.next = None

    return new_head
```

特点：

> 先处理后面的链表，再把当前节点接上去。

---

## 模式二：先处理当前节点，再递归

典型题目：

- 合并两个有序链表
- 删除链表节点
- 遍历链表

例如：

```python
def mergeTwoLists(l1, l2):
    if l1 is None:
        return l2

    if l2 is None:
        return l1

    if l1.val <= l2.val:
        l1.next = mergeTwoLists(l1.next, l2)
        return l1
    else:
        l2.next = mergeTwoLists(l1, l2.next)
        return l2
```

特点：

> 当前节点先确定，后面的事情交给递归。

# 7. 递归最容易错的地方

## 错误一：忘记终止条件

比如反转链表如果没有：

```python
if head is None or head.next is None:
    return head
```

递归会一直调用下去，最后爆栈。

---

## 错误二：不知道递归函数返回什么

这是最常见的问题。

比如反转链表中：

```python
new_head = reverseList(head.next)
```

这里的 `new_head` 是：

> 反转后的新链表头节点。

不是 `head.next`，也不是原来的 `head`。

---

## 错误三：指针接错

反转链表中这两行非常关键：

```python
head.next.next = head
head.next = None
```

如果忘了：

```python
head.next = None
```

可能会形成环。

比如：

```text
1 -> 2 -> 3
```

反转到 `1` 这一层时，如果不断开 `1.next`，可能变成：

```text
3 -> 2 -> 1 -> 2 -> 1 -> 2 ...
```

形成环。

---

## 错误四：Python 递归深度限制

Python 默认递归深度有限制，一般大约是 1000 层左右。

所以如果链表特别长，递归可能会报错：

```text
RecursionError: maximum recursion depth exceeded
```

因此在实际面试中：

- 链表题递归写法优雅
- 迭代写法更稳

比如反转链表，面试中建议两种都掌握。

# 8. 递归思维训练方法

做链表递归题时，可以按这个步骤来：

## 第一步：写函数语义

比如：

```python
def reverseList(head):
    """
    返回反转后的链表头节点
    """
```

## 第二步：写终止条件

```python
if head is None or head.next is None:
    return head
```

## 第三步：相信递归

```python
new_head = reverseList(head.next)
```

意思是：

> 后面的链表已经处理好了。

## 第四步：处理当前节点

比如：

```python
head.next.next = head
head.next = None
```

## 第五步：返回结果

```python
return new_head
```

# 9. 一个万能理解方式

对于链表递归，你可以把链表拆成：

```text
head + 后面的链表
```

递归函数处理整个链表。

所以：

```python
func(head)
```

表示处理整条链表。

```python
func(head.next)
```

表示处理 `head` 后面的子链表。

当前层只需要关心：

```text
head 和 func(head.next) 的结果怎么连接
```

# 10. 总结

链表递归的本质是：

```text
当前节点 head 先别管后面的细节，
后面的链表交给递归处理，
当前层只负责把 head 和递归结果接起来。
```

最重要的三句话：

```python
# 1. 函数定义是什么？
# 2. 什么时候结束？
# 3. 当前层怎么连接递归结果？
```

比如反转链表：

```python
def reverseList(head):
    if head is None or head.next is None:
        return head

    new_head = reverseList(head.next)

    head.next.next = head
    head.next = None

    return new_head
```
